# AWS S3 Multiple Image Hosting Project

## Objective

Host and display multiple images using Amazon S3 Static Website Hosting.

## AWS Services Used

* Amazon S3
* S3 Bucket Policy
* Static Website Hosting

## Bucket Name

`ashwini-s3-image-hosting`

## Features

* Upload multiple image files to Amazon S3
* Configure public read access using bucket policies
* Generate public object URLs
* Display multiple images in an HTML gallery page
* Access the gallery using the S3 website endpoint

## Steps Performed

1. Created an S3 bucket in the AWS Mumbai region.
2. Uploaded multiple image files.
3. Disabled block public access settings.
4. Added a bucket policy for public object access.
5. Created a `gallery.html` file to display images.
6. Enabled static website hosting.
7. Verified the gallery through the S3 website endpoint.

## Outcome

Successfully deployed a publicly accessible static image gallery hosted entirely on Amazon S3.
